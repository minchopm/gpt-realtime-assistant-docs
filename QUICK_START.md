# GPT Realtime Assistant — quick start

## Goal

Complete one small, verifiable task before using the workflow for a larger project.

## Before you begin

Use the current product from the official source. Check its device requirements and entitlements; a free download does not necessarily mean every operation is free. The feature table records product-specific limits.

## Steps

1. Choose the session purpose: translation, live questions, or a structured meeting/lecture note. Tell other participants when you will capture their speech.

2. Confirm the installed version, your subscription and available credits for an online session. On an Apple Silicon Mac, select a prepared local mode if that is the intended workflow.

3. Choose a relevant template or write a focused instruction. For translation, choose both languages and the spoken-translation option.

4. Check microphone input and playback volume. Put the device where both speakers can be heard without competing background speech.

5. Start a brief test with a simple sentence and a number. Read the transcript and listen to the reply before beginning the real conversation.

6. During the session, pause to correct important terms. Add an image only when it is necessary to answer the current question.

7. End the session explicitly. Review saved notes and proposed tasks, confirm dates and names, and check the displayed credit balance.

## Verify the result

Return to the saved output or record rather than relying only on the preview. Check the specific items described in the steps above. If the result differs, keep the original input and reproduce the issue with a small, non-sensitive example.
