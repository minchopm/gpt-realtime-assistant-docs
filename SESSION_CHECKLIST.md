# Session acceptance checklist

This is an operational check, not a performance benchmark or an approval certificate.

## Select the purpose

Choose translation, contextual voice assistance or a structured note. State whether the desired output is a transcript, a draft explanation or confirmed action items.

## Check the processing path

Online sessions send audio/context to OpenAI. The documented Apple Silicon local mode supports prepared local transcription and written answers. Confirm the mode before sharing content.

## Run a short test

Speak a new sentence containing a number and a name. Inspect recognition, language direction and the intended spoken or written reply. Test fresh offline processing separately if planned.

## Close the session

End explicitly, check the final credit balance, then review notes and task ownership against the conversation. Do not distribute unverified inferred decisions.

## Pass criteria

The selected mode works under the intended connectivity, important names/numbers are verified, saved notes are accessible, and proposed actions are clearly distinguished from agreed actions.
